# Community Support

## Where to ask

- Usage, setup, and contribution questions: open a GitHub discussion if enabled,
  or a question issue using the repository template.
- Reproducible defects: use the bug report template.
- Scenario proposals: use the scenario proposal template before substantial work.
- Private support contact: [support@astralabs-ai.net](mailto:support@astralabs-ai.net).

Community support is provided on a best-effort basis with no guaranteed response
or resolution time. Include the Astra CE version or commit, operating system,
reproduction steps, expected result, and sanitised logs. Never post credentials,
tokens, personal data, confidential evidence, or customer records.

Security vulnerabilities must be reported privately under
[`SECURITY.md`](SECURITY.md), not through a public support channel. Conduct
concerns follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

The issue tracker is for actionable project work. Maintainers may redirect
environment-specific consulting, unsupported modifications, or general GRC/legal
advice. Community responses are technical information, not legal, audit, or
compliance certification advice.
